# Python Öğrenme Günlüğü

Yönetim Bilişim Sistemleri son sınıf öğrencisiyim ve data analyst + görüntü işleme 
alanına yöneliyorum. Bu depo, Python'u sıfırdan öğrenme sürecimin kayıtlarını içeriyor.

## Hafta 1: Python Temelleri

- **gun1_degiskenler.ipynb** — Veri tipleri (int, float, str, bool), aritmetik işlemler, 
  string birleştirme (f-string), type(), input()
- **gun2_listeler_dict.ipynb** — Listeler, tuple, dictionary, slicing, mutable/immutable 
  kavramı, liste metodları (append, insert, remove, pop, sort)
- **gun3_koşullar.ipynb** — if/elif/else, karşılaştırma ve mantıksal operatörler 
  (and, or, not)
- **gun4_donguler.ipynb** — for ve while döngüleri, range(), break/continue, 
  enumerate(), zip(), dictionary üzerinde gezinme
- **gun5_fonksiyonlar.ipynb** — Fonksiyon tanımlama, parametreler, return, 
  varsayılan değerler

## Mini Projeler

- Envanter/stok takip sistemi (döngüler + koşullar + dictionary kullanılarak)
